# Flim Brand Assets

## Official Primary Logo

Asset: `client/public/brand/flim-logo-primary.png`

Description: gold cinematic film reel, black film strip, gold FLIM namemark, black/gold backing, transparent background.

Use for:

- Primary web header
- Branded login and onboarding where the full brand is appropriate
- Marketing lockups
- Full-size Flim branding
- Documents requiring the full brand

Do not replace it with:

- Previous orange film-ticket logo
- Generic play icon
- Plain text Flim
- Old generated logo concepts
- Backlot Arcade logo

## Official Secondary Icon Mark

Asset source: `client/public/brand/flim-icon-mark-source.png`

Description: gold film reel with black/gold film strip and no FLIM namemark.

Use for:

- Mobile app icon
- Favicon
- Compact icon contexts
- Shortcuts
- Square/icon-only uses

The icon mark is separate from the primary namemark logo. Do not use the compact icon where the full primary Flim brand is intended.
